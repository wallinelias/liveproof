# LiveProof (Junction 2026, City of Espoo challenge "Rethinking Recruitment")
Solo hackathon project. Final submission deadline: Sun 15 Nov 10:00 (hard).
The money budget is tiny. Be token-frugal. Read SPEC.md for WHAT to build and TODO.md for status.
Do not re-read files you do not need. Do not explore the whole repo.

## Rules
- Mobile-first web app: React + Vite + Tailwind. Static, no backend, no accounts, no paid services.
  State lives in memory + seeded JSON in src/data. No API keys or secrets in code, ever.
- All data is synthetic. Obviously fictional names and companies. No real personal data.
- RED LINES (never break): AI never scores, ranks or filters people. Humans make every hiring step.
  Submissions are shown in RANDOM order. Talent identity stays hidden until the talent chooses to reveal it.
- Keep code small and plain. Few dependencies. Justify any new library in ARCHITECTURE.md first.
- Verify with `npm run build` before saying a milestone is done. Git commit after each milestone.
- Replies are short. Summaries max 10 lines. Never paste code back into chat.
- Stay inside this folder. Never delete or modify anything outside it.
